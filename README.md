  Este projeto consiste em um sistema de cadastro de produtos desenvolvido como uma aplicação prática para gerenciamento de dados.
  O objetivo principal foi criar uma interface funcional que permita adicionar/ler/editar/remover produtos,
  aplicando conceitos de lógica de programação e banco de dados.
